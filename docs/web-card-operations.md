# 网站卡片插件运维说明

## 配置顺序

1. 打开“Agent 工作台”，粘贴样例 URL 并描述卡片样式、目标群和推送方式。
2. 内置 Agent 生成包含站点、解析、模板、群绑定和采集任务的完整方案。
3. 在右侧检查方案与卡片预览，然后选择应用或放弃。
4. 需要 Cookie、Authorization 或 API Key 时，在安全凭据区直接写入 Secret Store。
5. 站点、模板、绑定和采集的高级页面仅用于审计、启停和故障修复。

## Agent 修改

插件内置并固定使用 `builtin-web-card-studio`，管理员无需选择或配置 Agent。Agent 产生完整工作区方案，管理员必须应用或拒绝。应用会复用匹配资源并创建新的不可变模板版本；只有方案明确要求发布且预览成功后，自动流程才切换到新版本。

## 凭据与安全

自定义 Headers 的值存放在宿主插件 Secret Store 中。列表、API、日志和 Agent 上下文只显示 Header 名称或脱敏值。需要在宿主配置 `yudream.plugin.secret-key`，值为 Base64 编码的 32 字节密钥。

跨域重定向默认移除敏感 Headers，且只允许站点明确配置的重定向域名。插件拒绝访问本地、内网、链路本地和多播地址。

## 采集与重试

采集任务首次运行默认处理入口中的最近 3 条，可在任务中调整。后续按规范化 URL 和内容键去重。不同群的投递相互独立；失败记录可以在“运行记录”中重试，重试不会重新发现历史内容。

## 限制

插件使用普通 HTTP 请求，不执行目标网站 JavaScript，不支持浏览器登录、验证码或扫码登录。Cookie 和 Token 过期后需要管理员手动更新 Headers。
