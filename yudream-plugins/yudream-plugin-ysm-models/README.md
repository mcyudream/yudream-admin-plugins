# 皮肤站玩家模型附属

在皮肤插件角色体系上提供原始 `.ysm` / 明文 ZIP 上传、通用格式转换、三维预览、贴图选择、装备和服务器共享模型库。用户仅管理本人模型与角色；跨用户管理使用独立管理员页面和权限。

管理员可在「模型设置」一键关闭所有上传（包括新版本），或开启上传审核。默认允许上传、无需审核；策略保存在插件文档存储并立即生效。配置权限为 `plugin:ysm-models:config`，审核与共享管理继续使用 `plugin:ysm-models:manage`。

开启审核后，新模型和新版本进入待审核，所有者仍可预览。管理员在「模型管理」按状态筛选、预览、通过或填写原因驳回。待审核 / 已驳回模型不能装备、共享或通过游戏桥接下载；开启 / 关闭审核不会追溯改变已有记录状态。上传新版本会替换当前版本并重新审核，审核期间已装备角色暂时恢复皮肤外观。网站只认识模型 schema，不绑定 Minecraft 或 Fabric 版本。

安装、运行端版本、权限与格式限制见 [运行端说明](../../ysm-runtime/README.md)。预览引用的开源许可证包含在插件 JAR 前端目录 `third-party/` 中。
